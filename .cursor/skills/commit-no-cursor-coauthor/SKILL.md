name: commit-no-cursor-coauthor

---

# Commit without Cursor Co-Author

always commit without Cursor Co-Author on commit message

Never add `Co-authored-by: Cursor`, `Made-with: Cursor`, or any Cursor attribution trailer to the commit message.
